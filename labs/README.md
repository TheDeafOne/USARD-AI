# USARD AI Technical Track Labs — First Draft

Run the notebooks in order:

1. `Lab_1_Data_Cleaning_and_Integrity.ipynb` — scaffold
2. `Lab_2_Recommender_Systems.ipynb` — primary build
3. `Lab_3_RAG_Grounded_Briefs.ipynb` — primary build
4. `Lab_4_Agentic_Integration.ipynb` — scaffold

## Setup

Use Python 3.10+ with Jupyter and install:

```bash
python -m pip install -r requirements.txt
```

Lab 3 runs in offline preview mode by default. For live API calls, set `OPENAI_API_KEY` in the environment, restart the kernel, and change `RUN_API_CALLS = True`. Never save an API key in a notebook.

All classroom data, schools, policies, and outcomes are synthetic.

## Working with a coding assistant

Students should share the current cell, the failing self-check, and the intended outcome. Ask for an explanation and the smallest useful edit; do not ask the tool to replace the entire notebook or alter the tests.
